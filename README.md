OncoTwin

Open, transparent, reproducible AI-assisted hypothesis generation for oncology research.

OncoTwin is a research-support tool designed to help researchers explore oncology cases, organize evidence, generate AI-assisted hypotheses, compare possible explanations, and maintain a transparent record of the reasoning process.

It is intended for research and educational use only. OncoTwin is not a medical device and does not provide medical diagnosis, treatment recommendations, or medical advice.

Features

- Firebase Authentication
- Open Case Workspace
- AI-assisted oncology hypothesis generation
- Multi-agent reasoning
- Evidence and reality-anchor status for generated hypotheses
- Benchmark / blind-validation workspace
- PubMed literature search
- Run history and decision logging
- Research report export
- Bring Your Own API Key (BYOK) support for supported AI providers
- User-specific Firestore data isolation
- Responsive dark/AMOLED interface

Research Disclaimer

OncoTwin is an experimental research-support application.

AI-generated hypotheses may be incomplete, incorrect, or unsupported by available evidence. Results must be independently verified against reliable scientific literature and appropriate expert judgment before being used for any research or real-world decision.

Do not use OncoTwin as a substitute for a qualified medical professional.
